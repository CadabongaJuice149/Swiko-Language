# ICU and Unicode notices

`LICENSE` is the unmodified upstream notice from ICU release 74.1:

https://raw.githubusercontent.com/unicode-org/icu/release-74-1/LICENSE

The verified Swift 6.0.3 Linux toolchain's
`usr/lib/swift_static/_foundation_unicode/uvernum.h` identifies ICU 74.1;
`uchar.h` identifies Unicode 15.1. The native Swiko distribution statically
links Foundation ICU components from that toolchain, so these upstream notices
are included alongside the Swift toolchain license.

This file documents provenance. It does not modify the upstream license or
grant an additional license to Swiko's original source.
